# RandomWallpaper 0.1.0 Preview 3

首个公开 Windows/.NET 扩展预览包，最低宿主 **Kikicast 0.2.0** /协议 SDK 1，未签名，不是安全沙盒。

## 安装

- ARM64 Windows：`RandomWallpaper-0.1.0-preview.3-win-arm64.kikicast`。
- x64 Windows：`RandomWallpaper-0.1.0-preview.3-win-x64.kikicast`。
- 在 Kikicast **Settings → Extensions → Refresh** 选择官方目录包并确认安装，或 **Import .kikicast** 导入匹配原生 OS 架构的包。ARM64 宿主不以仿真应用进程误选 x64 包。
- `.kikicast` 是包含 manifest/完整载荷 SHA-256/许可的 ZIP 容器，由宿主管理，不需手工解压或单独 helper 服务；自包含稳定 .NET 10，不依赖已安装 .NET、PowerShell 或旧 WallChanger。
- 首次配置 **默认禁用、空文件夹列表**；自行添加具名本地文件夹，选择 Desktop/Lock screen，Keep folder draft → Save extension settings，启用扩展及宿主 Extensions。没有任何发布的个人路径默认值。
- 安装/加载/列出/设置/更新/登录不更改壁纸，也不执行命令。只有主动运行文件夹命令/确认 DeleteNow 才有原生副作用。更新保留配置、UUID、袋状态及当前来源。

## 行为

桌面和锁屏使用 Windows 公开 API。具名文件夹保持持久化随机袋，尽量整轮不重复；排除当前文件/像素相同别名，单图或全为当前图时普通文件夹命令拒绝重用。仅当前用户本地固定盘顶层有界扫描，拒绝链接/网络/损坏/动画/超大图片；WebP 取决于 Windows 解码器支持。

**DeleteNow 是破坏性操作，需要每次默认 No 的确认**：核验记录的当前源图及 Windows 当前原始文件引用，优先同一文件夹中的不同有效图片，没有则按配置顺序尝试其他已启用文件夹。全请求共用安全预算；所有可用目录无替代图时保留源图。先替换，再核验仍引用原图的所有目标和原图身份，最后用公开回收 API送入回收站。无永久删除/提权回退，部分替换或不可核验时保留原图并报告结果。

Preview 3 修复锁屏 GetImageStream 可能被 Windows 转换、像素与原图不同引起的误拒绝：用公开 OriginalImageFile + 精确路径、文件 ID/长度/mtime/SHA/源像素强核验，不放宽为相似度。流设置/来源不可读/外部更改会保守拒绝。不缓存壁纸到扩展安装目录，卸载只删除安装/配置/状态/引用，**不会删除来源文件夹**。中断 pending 状态需手动备份/重置，重置本身不更改壁纸或源文件。

## 验收与风险

31 项生成目录/假 Windows 接口测试；发布 ARM64 `--describe` 原生检查、x64-on-ARM64 `--describe` 仿真检查只描述协议，不执行壁纸/回收/启动注册。用户已报告当前 ARM64 主机设置及此前失败的 DeleteNow 路径测试成功，但原生 x64、全部配置/策略、发布后的导入与完整安全/性能审计仍待验收。各资产的实际构建 source commit /检查范围见 `validation.json`；不发布私人图片/配置/截图。

可执行扩展具有当前用户权限；能力声明/哈希/独立进程不是权限隔离或可信签名。哈希仅核对下载完整性，勿关闭 Windows 安全保护。两个 Windows 目标与持久化/回收/壁纸/存储不是跨 API 原子事务；失败可能保留已成功设置的替代图，不宣称回滚系统状态。
